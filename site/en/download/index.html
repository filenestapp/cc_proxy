Install and connect

  1. Download and install the package for your system.
  2. Open aifree and enter your account email and password. The device name defaults to your computer's name; change it to something you'll recognise.
  3. Select Connect. The client creates a virtual network adapter, so your system asks for administrator approval once: your login password on macOS, a UAC prompt on Windows, polkit on Linux.
  4. Once connected, the home screen shows your exit IP. Closing the window keeps aifree running in the system tray; choosing Quit from the tray menu disconnects.

Installer signatures

Apple has notarized the macOS installer. The Windows installers are signed by TENSOR SHIFT PTE. LTD.

Environment check

The client's Environment check compares this device's exits, DNS, UDP and other signals to help troubleshoot connections. It sends some observations to a third-party checking service; see the privacy policy. It only runs when you start it.
