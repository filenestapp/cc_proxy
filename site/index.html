常见问题

aifree 是什么？

aifree 提供独享的海外住宅 IP 和配套的桌面客户端，让你访问 AI 服务时始终使用同一个住宅出口；Standard 和 Premium 套餐另含一个 AI 团队版席位。aifree 是独立服务，与任何 AI 公司没有隶属或合作关系。

什么是独享住宅 IP？和普通代理有什么区别？

住宅 IP 来自家庭宽带运营商，而不是数据中心。“独享”指这个 IP 只分配给你一个人使用。普通代理大多是多人共用的机房 IP，同一个地址上可能同时有很多陌生用户。

我所有的上网流量都会经过你们吗？

不会。客户端只把 AI 相关的域名送进隧道，其他网站本地直连，不经过我们的服务器。分流规则由服务端维护，客户端会自动更新。

你们能保证我的 AI 账号不被封禁吗？

不能，也没有任何服务能做出这样的保证。AI 服务商会根据自己的使用条款管理账号。稳定的独享出口能避免和陌生人共用 IP 带来的干扰，但请你遵守所用服务的条款和当地法律。

付款后多久可以用？

海外住宅 IP 套餐付款后自动分配，通常几分钟内即可在客户端连接。Standard 和 Premium 的住宅 IP 同样自动分配；AI 团队版席位由人工开通，完成后会邮件通知你。

支持哪些系统？一个账号能用几台设备？

支持 macOS（Apple 芯片）、Windows 和 Linux。可同时登录的设备数量以你的套餐为准，你可以在用户中心查看每台设备并随时让它下线。

IP 出了问题可以更换吗？

可以。如果你的出口 IP 无法正常使用，请发邮件到 support@aifree.sg，我们核实后会为你更换，客户端会自动切换到新 IP。

怎么取消订阅？能退款吗？

在用户中心点“管理订阅”即可取消，当期结束前仍可使用，到期后不再扣费。如果因为我们的原因无法开通或长期无法使用，请联系客服申请退款，详见服务条款。

@aifree.sg 邮箱是什么？

付费用户可以在用户中心开通一个 你的名字@aifree.sg 邮箱，通过网页收发邮件。订阅结束后邮箱会被停用。
